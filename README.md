# 모아랩 업무 워크스페이스

모아킷/모아랩 내부 업무 관리 웹앱. 웹앱 검증 · 원가계산 · 작품 갤러리 · 일정을 한 곳에서.
**모바일 우선** (폭 375px 기준으로 설계), PC는 같은 화면을 넓게 씁니다.

> 개발 배경·도메인 규칙·파일 지도는 [`CLAUDE.md`](./CLAUDE.md) 를 보세요.

---

## 처음 설정 (3단계)

### 1. Supabase 프로젝트 만들기

[supabase.com](https://supabase.com) 에서 새 프로젝트를 만든 뒤,
**SQL Editor** 에 [`supabase/schema.sql`](./supabase/schema.sql) 을 통째로 붙여넣고 **Run**.

이 한 번으로 아래가 전부 만들어집니다.

- 테이블 15개 (멤버 · 앱 · 라운드 · 체크 · 댓글 · 원가 · 갤러리 · 일정 · 로그)
- RLS 정책 (`members` 는 브라우저에서 접근 불가, PIN 노출 차단)
- Storage 버킷 3개 (`comment-files`, `cost-photos`, `gallery`) — 공개 읽기 + 인증된 쓰기
- 초기 멤버 5명

여러 번 실행해도 안전합니다.

### 2. 환경변수

```bash
cp .env.example .env.local
```

Supabase 대시보드 **Project Settings → API** 에서 세 값을 복사합니다.

| 변수 | 어디서 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `anon` `public` 키 |
| `SUPABASE_SERVICE_ROLE_KEY` | `service_role` 키 — **`NEXT_PUBLIC_` 을 붙이지 마세요** |

`service_role` 키는 PIN 검증과 멤버 관리 API에서만 쓰이며 브라우저로 나가지 않습니다.

### 3. 실행

```bash
npm install
npm run dev     # http://localhost:3000
```

첫 로그인 PIN은 **원장 `0000`** 입니다.
들어가서 `관리 → 멤버` 에서 **전원 PIN을 먼저 바꾸세요.**

| 이름 | 초기 PIN |
|---|---|
| 원장 | 0000 |
| 이서은 | 1111 |
| 주은서 | 2222 |
| 강지연 | 3333 |
| 윤창진 | 4444 |

## 쓰는 법

### 앱을 추가할 때 (원장)

`검증` 탭 → **+ 새 앱** → 이름 · 링크 · 목적 · 제작자 1명 · 검증자 1~3명 · 마감일.

저장하면 **1차 검증 라운드**와 (검증자 수 × 5항목)만큼의 체크 칸이 자동으로 생깁니다.
**앱이 늘어나도 코드를 고칠 필요가 없습니다.**

### 검증할 때 (강사)

앱을 열면 내 체크 카드가 맨 위에 있습니다. 5개 항목을 `미확인 / 통과 / 실패` 로 표시하고
아래 **검증 결과 저장** 을 누릅니다.

- `실패` 를 고르면 **무엇이 문제인지 적지 않으면 저장되지 않습니다.**
- 앱 상태는 자동으로 정해집니다 — 전원 전부 통과면 `검증 완료`, 하나라도 실패면 `수정 필요`.
- 폰에서 오류를 만나면 `댓글` 탭에서 **스크린샷을 바로 올려주세요.** 말로 설명하는 것보다 빠릅니다.

### 앱을 고쳤을 때 (제작자/원장)

앱 상세의 **🔄 수정했음 → 재검증 요청**.
수정 내용을 적으면 **N+1차 라운드**가 열리고 모든 체크가 `미확인` 으로 리셋됩니다.
이전 라운드는 접힌 상태로 남아 누가 언제 뭘 지적했는지 다 보입니다.

### 원가를 계산할 때

`원가` 탭 → 원가표 → **+ 항목**.
재료 사진 · 구매처 · 구매 링크까지 넣어두면 나중에 장 볼 때 그대로 씁니다.

- **소모품**: 묶음 수량 / 묶음 가격 / 1인 사용량
- **재사용품**: 재사용 체크 + 감가 회차 (드론 50회 등)
- **강사비·교통비**: 재사용 + 감가 회차 `1` 로 넣으면 "1회당 그 금액, 1인당 ÷ 인원" 이 됩니다

하단 고정 바에서 **인원수를 바꾸면 즉시 다시 계산됩니다.** 학교와 인원 협의할 때 이 숫자를 보세요.
마진율이 음수면 빨갛게 표시됩니다. **🛒 구매 목록 보기** 는 구매처별 장보기 리스트입니다.

### 사진을 모을 때

`갤러리` 탭 → **+ 앨범** (학교 + 날짜 + 프로그램) → 폰에서 여러 장 한 번에.
업로드할 때 자동으로 긴 변 1600px WebP로 줄여서 저장합니다.

**얼굴 포함 여부를 꼭 체크해주세요.** 체크된 사진은 `얼굴O` 뱃지가 붙고
외부용 다운로드(`얼굴 없는 것만 받기`)에서 빠집니다.

`사진 모아보기` 모드에서 학교·프로그램·기간·태그로 걸러 여러 장을 골라 zip으로 받을 수 있습니다.

## 알아둘 것

- 사진을 지우면 DB 기록은 사라지지만 **Storage 버킷의 파일은 남습니다.** 많이 쌓이면 정리가 필요합니다.
- 내부 5~7명 전용 도구라 RLS를 느슨하게 뒀습니다 (`members` 만 예외). 외부에 공개하지 마세요.
- 로그인 세션은 localStorage에 30일 유지됩니다. 공용 PC에서는 로그아웃하세요.
